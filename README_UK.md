###

<h2>HTTP</h2>

Оскільки більшість сайтів у світі зараз підтримують HTTPS, MacDPI не обминає глибокий аналіз пакетів для HTTP запитів. Однак він все ж забезпечує з’єднання через проксі для всіх HTTP запитів.

<h2>HTTPS</h2>

Хоча TLS шифрує кожен процес з’єднання, доменні імена все ще відображаються як текст у пакеті Client Hello. Іншими словами, якщо хтось інший подивиться на пакет, він може легко здогадатися, куди спрямований пакет. Доменне ім’я може надати важливу інформацію під час обробки DPI, і ми можемо побачити, що з’єднання блокується одразу після відправлення пакету Client Hello. Я спробував різні способи обійти це і виявив, що, здається, лише перший фрагмент пакету перевіряється, коли ми відправляємо пакет Client Hello, розбитий на частини. Що MacDPI робить для обходу цього, так це відправляє перший байт запиту на сервер, а потім відправляє решту.
